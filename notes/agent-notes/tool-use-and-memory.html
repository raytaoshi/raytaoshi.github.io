Tool Use and Memory

Agent Notes · Last updated August 2026

Tools extend what an agent can do; memory extends what it can retain. Both require careful selection, validation, and access control.

Tool contracts

Each tool needs a clear purpose, typed inputs, predictable outputs, and explicit failure behavior. Before execution, validate arguments and permissions; afterward, treat returned content as data rather than trusted instructions.

Memory layers

Working memory holds current-task context, episodic memory records prior interactions, and semantic memory stores durable facts. Retrieval should optimize relevance while preserving provenance and respecting privacy.

Security boundary

Use least privilege, confirmation for consequential actions, and audit logs. Memory writes also require validation because poisoned or outdated records can influence future decisions. These controls belong in the agent architecture.
