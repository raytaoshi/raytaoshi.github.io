Public-Key Cryptography

Cryptography Knowledge · Last updated August 2026

Public-key systems separate public and private key material, enabling secure key establishment and authentication without a pre-shared secret.

Key pairs

The public key can be distributed, while the private key must remain controlled by its owner. Security relies on a well-studied hard problem and correct parameter choices.

Hybrid encryption

Public-key operations are comparatively expensive, so protocols usually use them to establish a session key and protect bulk data with symmetric authenticated encryption.

Authenticity

A public key is only useful when reliably bound to an identity. Certificates, trust stores, fingerprints, and authenticated key exchange address this binding problem.
