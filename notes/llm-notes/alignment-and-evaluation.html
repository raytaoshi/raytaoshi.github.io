Alignment and Evaluation

LLM Notes · Last updated August 2026

Alignment asks whether model behavior matches intended goals and constraints; evaluation supplies evidence across representative and adversarial settings.

Multiple dimensions

Useful behavior combines task performance, factuality, instruction following, robustness, fairness, privacy, and safety. A single aggregate score can conceal serious regressions in one dimension.

Evaluation design

Use held-out tasks, human judgments, calibrated automatic metrics, and red-team cases. Report prompts, sampling settings, grading procedures, uncertainty, and contamination controls so results can be interpreted.

Continuous process

Evaluation should follow the model through training, deployment, and observed distribution shift. Agentic use adds risks from tools and state, discussed in Tool Use and Memory.
