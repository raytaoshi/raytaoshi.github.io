Transformer Architecture

LLM Notes · Last updated August 2026

Transformers process sequences through attention, position-aware representations, and repeated residual blocks.

Token representations

Input tokens are mapped to embeddings and combined with positional information. The resulting vectors carry both token identity and location into the model stack.

Self-attention

Queries, keys, and values let each token aggregate information from permitted positions. Multi-head attention learns several interaction patterns in parallel, while causal masking prevents decoder-only models from seeing future tokens.

Residual blocks

Attention and feed-forward sublayers are wrapped by residual connections and normalization. Stacking these blocks builds contextual representations that are converted into next-token probabilities, the starting point for pretraining and fine-tuning.
