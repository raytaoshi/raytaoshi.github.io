Representation Learning

Advanced Deep Learning Notes · Last updated August 2026

Representation learning transforms raw observations into features that make relevant structure accessible to downstream tasks.

Objectives shape invariance

Supervised labels, reconstruction, contrastive pairs, masking, and prediction each reward different information. Data augmentations encode assumptions about which changes should leave a representation stable.

Assessing representations

Linear probes, transfer learning, retrieval, clustering, and robustness tests reveal different properties. Strong probe performance does not by itself prove that the model uses the probed feature.

Latent structure

Useful representations can support interpolation and controlled generation. This connects discriminative feature learning with the latent spaces used by generative models.
