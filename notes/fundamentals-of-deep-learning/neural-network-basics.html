Neural Network Basics

Fundamentals of Deep Learning · Last updated August 2026

A neural network composes parameterized transformations to approximate a mapping from inputs to useful outputs.

Layers and activations

A layer applies a weighted transformation followed by a nonlinear activation. Without nonlinearity, stacking linear layers would still represent only a linear transformation.

Learning objective

A loss function measures disagreement between predictions and targets. Training searches for parameters that reduce expected loss on data, while validation estimates performance beyond the training examples.

Generalization

Capacity, data quality, regularization, and optimization jointly determine whether the network learns reusable structure or memorizes noise. Parameter updates are computed through backpropagation.
