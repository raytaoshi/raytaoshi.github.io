Backpropagation

Fundamentals of Deep Learning · Last updated August 2026

Backpropagation efficiently applies the chain rule to compute how every differentiable parameter influences the loss.

Forward pass

The network computes intermediate values and a final loss. These values form a computational graph that records dependencies between operations.

Reverse pass

Starting from the loss, gradients flow backward through local derivatives. Shared paths accumulate gradient contributions, producing one derivative for each parameter.

Parameter update

An optimizer uses the gradients to update parameters. Gradient checks, stable activations, normalization, and sensible initialization help diagnose vanishing, exploding, or incorrect gradients.
